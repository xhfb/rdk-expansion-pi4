# 嘉立创 EDA 专业版：面向 Agent 的结构化导出

PDF 适合人工核对图形，但不适合作为 Agent 唯一输入。对于本项目，推荐同时交付以下
三层资料：

1. **工程/文档源码**：`.epro` 工程以及单页 `.esch`，保留元件、属性和图元。
2. **嘉立创 EDA 网表**：`.enet`，提供元件、引脚、封装和网络连接，是最适合自动比对
   电气关系的原始结构化文本。
3. **机器清单**：由源码和网表整理的 `hardware/board_v1.yaml`，显式补充主机映射、
   有效电平、电压域、共享资源和安全约束。

## 导出网表

在嘉立创 EDA 专业版原理图编辑器中：

```text
顶部菜单 → 文件 → 导出 → 导出网表
```

也可以使用：

```text
顶部菜单 → 导出 → 网表
```

导出类型选择“嘉立创 EDA”，页面范围选择整个工程，并在器件/封装属性中保留位号、
器件名称、封装和值等字段。导出的 `.enet` 是文本格式，可以进入版本控制并直接被
脚本解析。

官方说明：

- [导出网表](https://prodocs.lceda.cn/cn/schematic/export-netlist/)
- [导出文件源码](https://prodocs.lceda.cn/cn/pcb/file-file-source/index.html)

## 导出源码

“文件源码”功能可导出或查看当前文档的结构化源码。单独的原理图/PCB 源码主要用于
检查和归档；官方说明指出，若要重新导入编辑，应导出完整工程，而不是只依赖单个
文档源码。

## 给 Agent 的提交清单

每次硬件修订应一起提交：

```text
完整工程文件
所有原理图页源码
整个工程的 .enet
原理图 PDF
PCB PDF 或 Gerber
hardware/board_v1.yaml
```

然后运行：

```bash
python tools/validate_hardware_manifest.py
```

不要只提供 PDF，也不要只提供早期的接口表。网表能回答“哪些引脚电气相连”，但不能
完整表达有效电平、主机兼容性和倒灌风险，因此仍需要 YAML 清单与中文硬件参考。
