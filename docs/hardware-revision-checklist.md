# V1.0 硬件修订清单

本文只记录需要由硬件 Agent/工程师处理的项目；本次软件实现不修改 EDA 源文件。

## 必须修改

1. **U14 ADS1115 ADDR 接 GND**
   - 当前网表中 U14 pin 1 无网络。
   - 修订后地址固定为 `0x48`，与驱动默认值一致。

2. **增加主机 5V 隔离**
   - `5V_SYS` 当前直接连接 CN2 pin 2/4。
   - 增加可拔跳帽、焊桥或合适的电源路径控制，避免 USB-C 与板载降压同时供电时倒灌。

3. **隔离 DC007 与 XT30**
   - 当前两个输入直接汇合。
   - 使用独立保险和理想二极管/肖特基 OR-ing，或删除其中一个装配选项。

4. **修正外接蜂鸣器接口**
   - 当前 BUZZ 接口暴露原始 3.3V GPIO 和 5V_SYS。
   - 改为 `5V_SYS + Q8漏极开关端`，或改成 `5V_SYS + GND + 3.3V逻辑` 三针模块接口。

## 建议修改

- 丝印同时标注板卡逻辑名与物理针，例如 `I2C5 / PIN3,5`、`SPI / PIN19-26`。
- `SPI1_SCL` 更名为 `SPI_SCLK`，避免与 I²C SCL 混淆。
- 继电器接口标注 `5V / CTRL_3V3 / GND`，不要暗示板上有干接点继电器。
- FAN 丝印明确为 `5V_SERVO ALWAYS ON`。
- CAN 丝印明确为 `PASS-THROUGH ONLY`，并考虑增加 ESD、可选 120Ω 终端与共模电感。
- 对 12V、5V_SYS、5V_SERVO 输出补充额定电流和保险说明。
- 将最终电路重新导出 `.enet` 后更新 YAML 指纹和地址状态，并重新运行验证器。
